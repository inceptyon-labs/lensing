## MEDIUM-HIGH Findings

### MH-1: Unauthenticated REST Server on 0.0.0.0

**File:** `packages/core/src/rest-server.ts:1106`
```typescript
server.listen(port, '0.0.0.0', () => {
```

The HTTP server binds on all network interfaces with no authentication. Endpoints like `/settings`, `/plugins/install`, `/layout`, `/plugins/{id}/config`, and `/modules/{id}/restart` are fully accessible to any device on the local network.

**Recommendation:** Bind to `127.0.0.1` by default. Add authentication middleware (shared secret/token) for all administrative endpoints.

### MH-2: API Keys Embedded in URL Query Strings

**File:** `packages/core/src/allergies-server.ts:110`
```typescript
return `https://api.ambeedata.com/latest/pollen?...&x-api-key=${apiKey}`;
```

**File:** `packages/core/src/weather-server.ts:284`
```typescript
return `${base}?...&appid=${apiKey}&...`;
```

API keys in query strings can leak via server logs, browser history, referrer headers, or error reporting.

**Recommendation:** Move API keys to request headers where the API supports it.

### MH-3: postMessage with Wildcard Origin, No Source Validation

**File:** `apps/display/src/lib/IframeWidget.svelte:20,26-33`

Uses `postMessage(..., '*')` (necessary for srcdoc iframes) but the parent listener does not validate `event.source === iframeEl.contentWindow`.

**Recommendation:** Add `event.source` check to prevent spoofed messages from other frames.

### MH-4: Dynamically Constructed GitHub API URLs

**File:** `packages/core/src/publisher.ts:42-45`
```typescript
const [, owner, repo] = match;
const apiBase = `https://api.github.com/repos/${owner}/${repo}`;
```

Owner/repo extracted from user-provided URL without explicit alphanumeric validation.

**Recommendation:** Validate `owner` and `repo` match `/^[a-zA-Z0-9_.-]+$/`.

## MEDIUM Findings

### M-1: CDN Assets Without Subresource Integrity

**File:** `apps/display/src/app.html:10-12`

GridStack CSS and JS loaded from jsDelivr without `integrity` and `crossorigin` attributes.

**Recommendation:** Add SRI hashes.

### M-2: No Timeout on CalDAV Requests

**File:** `packages/core/src/caldav-client.ts:228`

CalDAV requests lack `AbortController` timeout. A slow server could hang indefinitely.

**Recommendation:** Add configurable timeout (30s).

### M-3: Shell Command Injection in Display Control

**File:** `packages/core/src/display-control.ts:25-27`
```typescript
const cmd = `DISPLAY=${display} xset dpms force ${mode}`;
exec(cmd, (err) => { ... });
```

The `display` parameter is string-interpolated into a shell command. A malicious value could execute arbitrary commands.

**Recommendation:** Use `execFile()` instead of `exec()`, or validate `display` against `/^:\d+$/`.

### M-4: gpiomon execSync with Shell

**File:** `packages/core/src/gpio-linux.ts:10`

Uses `execSync('gpiomon --version 2>&1')` which invokes a shell. The command is hardcoded and safe, but prefer `execFileSync`.

### M-5: Display Hardware System Commands

**File:** `packages/core/src/display-hardware.ts:42`

Executes `ddcutil`, `xrandr`, `which` via `execFileSync` (safe — no shell). Attack surface exists if arguments become user-controllable.

### M-6: Marketplace Plugin Download from Arbitrary URLs

**File:** `packages/core/src/marketplace-install.ts:25-41`

SSRF blocklist is applied, but any public URL is accepted for plugin downloads. Combined with no auth (MH-1), any network device could install malicious plugins.

**Recommendation:** Add domain allowlist for plugin downloads. Combine with authentication.

### M-7: WebSocket Endpoint Has No Authentication

**File:** `packages/core/src/agent-gateway.ts:57`

WebSocket connections lack authentication tokens. Any device on the network can connect.

**Recommendation:** Implement token-based WebSocket authentication.

## Recommendations (Priority Order)

1. **Add authentication to REST server** (MH-1, M-6, M-7) — Highest practical risk. Shared secret or token-based auth for all admin endpoints and WebSocket upgrade.
2. **Bind to 127.0.0.1 by default** (MH-1) — Opt-in for 0.0.0.0 via config.
3. **Move API keys from query strings to headers** (MH-2) — Prevents key leakage.
4. **Switch display-control.ts from exec() to execFile()** (M-3) — Eliminates shell injection.
5. **Add SRI hashes to CDN assets** (M-1) — Supply chain protection.
6. **Add event.source validation on postMessage listener** (MH-3) — Prevents message spoofing.
7. **Add input validation for GitHub owner/repo** (MH-4) — Defense in depth.
8. **Add AbortController timeout to CalDAV requests** (M-2) — Prevents resource exhaustion.
9. **Update dependencies** — svelte, @sveltejs/kit, rollup, minimatch have known CVEs.
10. **Add plugin download domain allowlist** (M-6) — Restrict to trusted sources.
